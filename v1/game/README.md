# Game Prototype (v1)

Minimal browser 3D prototype: TypeScript + Three.js + Vite.

## Requirements

- Node.js and npm

## Setup

```bash
npm install
```

## Run (dev server)

```bash
npm run dev
```

Open the printed URL (default http://localhost:5173/).

Controls: W/A/S/D to move.

## Other commands

```bash
npm run build    # type-check + production build
npm run preview  # preview the production build
```
